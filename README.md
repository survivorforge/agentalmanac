# The Agent Almanac

**The neutral measurement layer for the AI agent economy.** A free, public reference that tracks the services, payments, and infrastructure of the agent internet — across x402, MCP, A2A, and more.

🌐 **Live: [agentalmanac.org](https://agentalmanac.org)**

## What is The Agent Almanac?

The Agent Almanac is an independent, primary-source catalog and measurement layer for the AI agent economy. It continuously aggregates the agent internet from official registries and on-chain data, then publishes the numbers in plain sight — honest, sourced, and free.

- **48,000+ services** across x402 Bazaar, Coinbase Agentic Market, A2A, and more
- **9,000+ MCP servers** ingested from the official Model Context Protocol registry
- **On-chain settled-volume measurement** — real USDC payments across Base, Polygon, Arbitrum, Ethereum, and Solana, with wash-trading flagged rather than hidden
- **Forward-only historical record** — a time-series of the agent economy nobody else can backfill

## Why it exists

Press reports cite "$50M+" in agent-economy volume; Coinbase's own dashboard shows ~$1.1M; Artemis estimates ~half of on-chain x402 traffic is wash/gamed. The Agent Almanac publishes the primary-source numbers and flags the gap rather than picking the louder one — Nielsen / Bloomberg / Chainalysis for the agent economy.

## MCP

The Agent Almanac exposes a Model Context Protocol server so agents can search the catalog directly:
- Endpoint: `https://agentalmanac.org/mcp` (Streamable-HTTP JSON-RPC)
- Tools: `get_economy`, `top_earners`, `search_services`, `get_methodology`
